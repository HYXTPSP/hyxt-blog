在随身WiFi上开一个MC怀旧服

2025-06-19 #教程 #Minecraft #OpenStick #Genisys
🎮

前言

你有没有想过，一个几十块钱的随身WiFi设备，居然能跑起一个Minecraft服务器？

今天我就来分享一下，如何把一个廉价的OpenStick随身WiFi刷成Linux系统，然后在上面运行一个MCPE 0.14的怀旧服务器。

什么是MCPE 0.14？ MCPE (Minecraft Pocket Edition) 0.14 是2016年发布的老版本，属于"远古时代"的MCPE。很多人对这个版本有特殊的情怀，所以今天我们就来复刻一下当年的感觉。

硬件准备

  • OpenStick随身WiFi - 我用的是基于MSM8916芯片的版本，淘宝几十块钱就能买到
  • 电脑 - 用于刷机和SSH连接
  • USB数据线 - 连接随身WiFi和电脑

系统刷机

首先需要把随身WiFi刷成Debian系统。这一步比较复杂，需要拆机短接测试点进入9008模式，然后使用QPST工具刷入固件。

注意 刷机有风险，可能会变砖。请确保你了解风险后再操作。具体的刷机教程可以参考恩山论坛的相关帖子。

刷完机后，通过SSH连接到设备：

ssh root@192.168.1.3
# 默认密码: 1313144

环境配置

连接成功后，需要安装必要的软件包：

# 更新软件源
apt update

# 安装必要工具
apt install -y build-essential autoconf pkg-config libxml2-dev libsqlite3-dev libcurl4-openssl-dev libssl-dev libgmp-dev libzip-dev libpng-dev libonig-dev libjpeg-dev libfreetype-dev

编译PHP

Genisys服务器需要PHP 7.0 ZTS版本（带线程安全支持）。我们需要从源码编译：

下载PHP 7.0.33源码：

cd /root
wget https://www.php.net/distributions/php-7.0.33.tar.gz
tar xzf php-7.0.33.tar.gz

配置编译选项：

cd php-7.0.33
./configure \
    --prefix=/root/php70-zts \
    --enable-maintainer-zts \
    --enable-mbstring \
    --enable-sockets \
    --with-curl \
    --with-openssl \
    --with-zlib \
    --with-gmp \
    --with-sqlite3 \
    --enable-phar \
    --enable-xml \
    --enable-dom \
    --disable-cgi \
    --disable-phpdbg \
    --enable-cli \
    --disable-opcache \
    --disable-fileinfo \
    --without-pear \
    CFLAGS="-O1"

编译并安装（这一步比较慢，耐心等待）：

make -j1
make install

安装pthreads扩展：

cd /root
wget https://github.com/krakjoe/pthreads/archive/refs/tags/v3.1.6.zip
unzip v3.1.6.zip
cd pthreads-3.1.6
/root/php70-zts/bin/phpize
./configure --with-php-config=/root/php70-zts/bin/php-config
make -j1
make install

安装yaml和bcmath扩展：

# yaml
cd /root
wget https://pecl.php.net/get/yaml-2.1.0.tgz
tar xzf yaml-2.1.0.tgz
cd yaml-2.1.0
/root/php70-zts/bin/phpize
./configure --with-php-config=/root/php70-zts/bin/php-config
make -j1
make install

# bcmath (使用PHP源码中的扩展)
cd /root/php-7.0.33/ext/bcmath
/root/php70-zts/bin/phpize
./configure --with-php-config=/root/php70-zts/bin/php-config
make -j1
make install

创建php.ini配置文件：

cat > /root/php70-zts/lib/php.ini << 'EOF'
extension=pthreads.so
extension=yaml.so
extension=bcmath.so
EOF

部署服务器

PHP环境准备好后，就可以部署Genisys服务器了：

下载Genisys服务器核心：

mkdir -p /root/server
cd /root/server
# 从开服包中获取PocketMine-MP.phar

上传插件到plugins目录：

mkdir -p /root/server/plugins
# 将.phar插件文件上传到此目录

启动服务器：

cd /root/server
/root/php70-zts/bin/php PocketMine-MP.phar --no-wizard

服务器插件

我为这个服务器配置了以下插件：

插件 功能
登录插件 (Protection) 玩家注册/登录系统
经济核心 (EconomyAPI) 游戏内经济系统
领地 (FResidence) 领地保护系统
座椅 (Seat) 可以坐在椅子上
邮件 (ServerMail) 玩家互发邮件
防OP滥用 (plcmd) 防止OP权限被滥用
生物插件 (WPureEntities) 生物生成控制
别踩白块 小游戏

一键开服包

为了方便大家快速开服，我打包了一个一键开服包，包含了所有必要的文件：

下载开服包 (4.7MB)
开服包使用方法
  1. 解压开服包到任意目录
  2. Linux用户运行 ./start.sh
  3. Windows用户双击 启动服务器.bat
  4. 等待服务器启动完成

连接服务器

服务器启动后，使用MCPE 0.14客户端连接：

  1. 打开Minecraft PE 0.14
  2. 点击"游戏"
  3. 点击"添加服务器"
  4. 输入服务器地址：你的IP:19132
  5. 点击"加入服务器"
服务器常用命令
  • /register 密码 密码 - 注册账号
  • /login 密码 - 登录
  • /tpa 玩家名 - 请求传送到其他玩家
  • /sethome - 设置家
  • /home - 回家
  • /gamemode 1 - 切换创造模式（需要OP）

性能表现

在OpenStick上的实际表现：

  • 启动时间：约15-20秒
  • 内存占用：约150-200MB
  • 支持玩家数：2-3人同时在线
  • 世界大小：建议不超过100MB
注意事项
  • 随身WiFi性能有限，不要期望能跑大型服务器
  • 建议定期备份存档
  • 如果服务器卡顿，可以尝试减小视距
  • 玩家数据和存档在 worlds/ 和 players/ 目录

总结

虽然随身WiFi的性能有限，但跑一个2-3人的MCPE 0.14怀旧服还是没问题的。整个过程最大的挑战是编译PHP和各种扩展，但只要按照步骤来，都能成功。

这种玩法最大的乐趣就在于"废物利用"——把一个几十块钱的设备变成一个能用的游戏服务器，很有成就感。

如果你也想体验一下，赶紧试试吧！
